# Lumora image checklist

Save each file at the exact path shown (inside `frontend/public`). Until a file exists, the site shows a labelled placeholder. Only use images whose licence allows your use (Unsplash, Pexels and Pixabay licences allow free use; always check each photo's page). Avoid watermarked images.

Search links open a site search for the term; pick a photo that matches the product, crop to **4:5 portrait (about 800×1000)** and save as `.jpg`.
